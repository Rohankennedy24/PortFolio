01 / SECURITY ANALYTICS

Insider Threat Detection System

Built a real-time anomaly-detection pipeline that learns personalized employee behavioural baselines from signals such as login frequency, data transfer activity and day-of-week patterns. Isolation Forest flags observations that deviate from the learned profile, while SHAP adds an explainability layer so an alert is not just a score but can be inspected through its contributing risk features.

PROBLEMIdentify unusual insider behaviour without relying only on static rules.
APPROACHBehavioural features → Isolation Forest → anomaly score → SHAP explanation.
OUTPUTRisk alerts with feature-level explanations for investigation.

02 / TIME-SERIES + NLP

Stock Price Prediction & Investment Decision Support

Built an ensemble workflow using Random Forest and LSTM models on 2,626 NVIDIA stock records. The Random Forest model achieved an R² of 0.9997 and MAE of 0.423 in the reported evaluation. The system also processes 3,080 financial news headlines with NLTK sentiment analysis and combines the modelling workflow with a Flask dashboard for confidence-scored Buy / Hold / Sell decision support.

DATA2,626 stock records + 3,080 financial news headlines.
MODELSRandom Forest + LSTM ensemble with NLTK sentiment analysis.
DEPLOYMENTFlask dashboard with charts and confidence-scored recommendations.

03 / CUSTOMER INTELLIGENCE

Intelligent Credit Card Customer Segmentation

Applied K-Means clustering to 8,950 customer records across 18 financial features to uncover behavioural groups. The optimal K was selected as 4 using the Elbow Method. PCA was then used to reduce the feature representation to two components, making the clusters easier to visualise and interpret as distinct customer segments for downstream business insight.

DATA8,950 customers across 18 financial features.
METHODElbow Method → K-Means with K=4 → PCA visualization.
INSIGHTDistinct behavioural segments that can support targeted analysis.

04 / AGENTIC AI

SHIELD-MAS: Self-Healing Multi-Agent AI

SHIELD-MAS is an ongoing multi-agent AI system focused on detecting incorrect or hallucinated output, tracing the responsible agent, repairing only the faulty component and continuing the workflow instead of restarting the entire execution. The architecture is designed around a sequence of LLM-based agents — Retriever, Planner, Reasoner, Tool Agent and Summarizer — with provenance tracking across the workflow.

When a response is suspected to be unreliable, the system is designed to move through hallucination detection, provenance analysis, agent attribution, counterfactual replay and targeted repair. The goal is to make multi-agent systems more reliable, accountable and computationally efficient by avoiding unnecessary full-workflow re-execution.

CORE IDEAFind the agent responsible for a faulty output instead of blaming the whole pipeline.
RECOVERYReplay the affected step, repair the suspected agent and resume from the same workflow point.
STATUSArchitecture, agent foundation, provenance and persistence are under active development.
